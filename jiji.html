Jiji search

Show more, process less.

An unsolicited redesign of Jiji’s search flow, from search to product page. It keeps the information buyers need and changes the order they see it in.

ForBuyers searching a crowded Nigerian marketplace

The short version

Problem
Marketplaces give price, ratings, seller details, badges and promotions the same visual weight, so nothing tells a buyer where to look first.
What I did
Compared Jiji, Jumia and Konga, then redesigned the search flow in five screens for desktop web and mobile, with a style guide and a prototype.
Outcome
A 5-screen flow on desktop and mobile with Top Picks, a Filter drawer and Compare. An untested concept; testing is next.

01 · The problem

Everything competes for attention at once.

Information overload isn’t one marketplace’s problem. It’s the pattern across the industry. All three give price, ratings, seller details, badges and promotions the same visual weight. I used Jiji as the example because most Nigerian buyers already know it, but the same thinking applies to any of them.

How might we

Show buyers more without making them process more?

03 · Key decisions

Three choices that change the order.

01

Give buyers a starting point

Top Picks sit above all results, labelled Best Overall, Best Value, Best Rated and Premium, so a long list starts with a reason to look. Each label is backed by the data.

Answers: change the hierarchy
02

Filters when you need them

Filters open as a drawer instead of a permanent sidebar, so results get the full width. Price ranges show item counts before you apply them.

Answers: keep the information
03

Compare to decide, not just browse

Up to 4 products side by side across 8 rows. Best Overall wins on balance, not on price alone, which shows buyers that value is more than price.

Answers: help buyers decide

04 · Accessibility decision

Prices in a darker green, so they’re easy to read.

Jiji’s bright green is hard to read on white, especially on small text like prices. Prices are what people read most when they search, so I made them a darker green. The bright green stays on buttons and icons.

05 · Visual design

One set of rules for every screen.

I cut the file down to one text colour, one brand green, one typeface and four corner radii, so every screen follows the same rules.

08 · What I learned

What this project taught me.

Hierarchy over removal

An interface can hold everything a user needs and still hide what matters most.

Accessibility is a design choice

Prices use a darker green because the bright brand green is hard to read on white.

What I’d test next

How long it takes buyers to shortlist a product compared with Jiji today, and whether they trust the Top Pick labels.

Still an untested concept

White text on the bright green buttons is also hard to read, so I’d test a darker button green next.
